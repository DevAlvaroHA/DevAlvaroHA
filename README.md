## Sobre mí

Desarrollo aplicaciones web de extremo a extremo y me ocupo también de la infraestructura que las sostiene. Trabajo con **React / Next.js** en el frontend, **Node.js, NestJS y Express** en el backend, y despliego sobre **Linux, Docker y Nginx** aplicando prácticas DevOps y de seguridad desde el primer commit.

Mi formación combina desarrollo, administración de sistemas y **ciberseguridad** (ethical hacking y análisis forense digital), lo que me permite diseñar soluciones pensando a la vez en la funcionalidad, el rendimiento y la superficie de ataque.

**En qué aporto valor:**

- Aplicaciones full-stack con API REST documentada (Swagger), autenticación JWT y validación estricta de entrada.
- Endurecimiento de servicios web: rate limiting, cabeceras de seguridad (Helmet, HSTS) y buenas prácticas OWASP.
- Contenerización y despliegue reproducible con Docker y Docker Compose, y automatización con Python y CI/CD.
- Administración de entornos Linux y Windows Server, redes, virtualización y firewalls.

I build web applications end to end and take care of the infrastructure behind them. I work with **React / Next.js** on the frontend, **Node.js, NestJS and Express** on the backend, and deploy on **Linux, Docker and Nginx**, applying DevOps and security practices from the very first commit.

My background combines software development, systems administration and **cybersecurity** (ethical hacking and digital forensics), which lets me design solutions with functionality, performance and attack surface in mind at the same time.

**Where I add value:**

- Full-stack applications with documented REST APIs (Swagger), JWT authentication and strict input validation.
- Web service hardening: rate limiting, security headers (Helmet, HSTS) and OWASP best practices.
- Containerisation and reproducible deployments with Docker and Docker Compose, plus automation with Python and CI/CD.
- Administration of Linux and Windows Server environments, networking, virtualisation and firewalls.
